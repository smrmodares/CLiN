# Data

This directory contains the released score exports from the original CLiN project repository.

- `human_scores.csv` — annotations/proxy outputs for the human-authored subset.
- `model_generated_scores.csv` — annotations/proxy outputs for the model-generated subset.

The files are copied **unchanged** from the source repository; original column names are therefore preserved, including names used in intermediate project exports.

The paper evaluates 200 short Persian literary texts in total: 100 human-authored and 100 model-generated texts across five themes (hope, despair, longing, love, and friendship). Human ratings cover Originality, Fluency, Elaboration, Creativity, Attractiveness, and Emotion.

For the definitive interpretation of each metric and the reported analyses, refer to the paper rather than inferring semantics from intermediate export column names alone.
